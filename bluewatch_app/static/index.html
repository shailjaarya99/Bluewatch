      1. Read the bands

        A scene holds 11 bands of light, including infrared our eyes cannot see. Oil, water and algae reflect these bands differently.

      2. Add five formulas

        For the Random Forest, NDWI, MNDWI, NDVI, an NIR/SWIR ratio and FAI make water, algae and floating material easier to tell apart. The U-Net reads the bands directly.

      3. Decide for every pixel

        The Random Forest asks 100 decision trees about each pixel. The U-Net also looks at the pixels around it. Several U-Nets are averaged for the final answer.

      4. Colour the map

        Each pixel gets its class colour. The slider sets how sure the model must be before a pixel is called oil.

      Not live video: Sentinel-2 passes over the same place about every 5 days. Speed here means seconds per scene.

      Advanced: check a table of pixels (CSV)

      A CSV with columns b1, b2, b3, b4, b5, b6, b7, b8, b8a, b11, b12 (and optionally label for a score). A pixel table has no neighbours, so this check always uses the Random Forest.
